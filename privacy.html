Privacy policy

Effective date: October 11, 2026. Maintainer: acrojimmy.

Purpose and information used

Djembe APK Uploader is a personal tool that transfers Android test builds from the owner's local runner to the owner's Google Drive. It processes APK files, file names, sizes, checksums, build identifiers, and the Drive file identifiers needed to verify uploads and provide a private download link.

Google authorization provides access and refresh tokens. The OAuth client configuration and tokens are stored in a restricted directory on the runner computer, outside the source checkout. Authorized local administrators and the runner service can access that directory.

Google permissions

The uploader requests only the Google Drive drive.file scope. This allows it to create and manage files associated with its authorization. It does not request Gmail or contacts permissions, and it does not request unrestricted access to all Drive files.

Use and sharing

Information is used to transfer builds, verify file integrity, maintain a build record, and let the owner download the latest APK. Google receives uploaded files and authorization requests to provide its Drive service. GitHub Actions receives build logs, checksums, and the private file link in the build summary.

The uploader does not sell Google user data, use it for advertising, or send it to AI model training services. It does not change uploaded files to public sharing. The owner controls any subsequent sharing in Google Drive.

Retention

Local APK archives are retained for 30 days; cleanup runs after successful artifact saves. Google Drive contains a replaceable latest APK. Google may retain prior file revisions or deleted files according to its service behavior. Authorization credentials remain on the runner until removed or replaced; access can also be revoked through the Google Account.

Control and deletion

The owner can delete uploaded APKs from Google Drive, stop the upload workflow, remove its local credentials, or revoke the uploader's connection through Google Account third-party connections. Revoking access prevents future authorized uploads until a new authorization is granted.

This information website

These static pages do not contain analytics, advertising, tracking scripts, forms, or Google sign-in. GitHub Pages hosts the website and may process normal website request information under GitHub's privacy statement.

Contact and changes

For general privacy questions, open an issue in the information repository. Issues are public; do not include credentials or personal information. Changes to this policy will be posted on this page with an updated effective date.
